# 标准技术分析研报模板 (Report Template)

```markdown
# 技术分析报告: [股票代码] [股票/ETF名称]
- **分析基准日期**: YYYY-MM-DD
- **市场分类**: A股 / 港股 / ETF / 美股
- **综合趋势定性**: [强势多头 / 偏多头 / 震荡整理 / 偏空头 / 极弱空头]

## 一、 量价基准数据 (Ground-Truth OHLCV)
| 字段 | 数值 | 说明 |
| :--- | :---: | :--- |
| 最新收盘价 | **[Close]** | 前复权 (QFQ) 收盘价 |
| 开 / 高 / 低 | [Open] / [High] / [Low] | 日内极值区间 |
| 成交量 (Volume) | [Volume] | 场内成交量 |
| 实时参考净值 (IOPV) | [IOPV] | (仅ETF可用) 估算单位净值 |
| 实时折溢价率 | [Discount/Premium %] | (仅ETF可用) 溢价/折价状态 |
| 基金总份额 | [Shares] 亿份 | (仅ETF可用) 主力场内沉淀份额 |

## 二、 移动平均线系统 (Moving Averages)
| 均线周期 | 数值 | 价格相对位置 |
| :--- | :---: | :--- |
| 10 EMA (短期动能) | [EMA10] | 站上均线 / 均线压制 |
| 20 SMA (月度中轴) | [SMA20] | 站上均线 / 均线压制 |
| 50 SMA (中期牛熊) | [SMA50] | 站上均线 / 均线压制 |
| 200 SMA (长期牛熊) | [SMA200] | 站上均线 / 均线压制 |

## 三、 核心技术指标矩阵
- **MACD**: DIF=[DIF], DEA=[DEA], 柱状图=[Hist] ➔ [金叉/死叉/动能评估]
- **RSI**: RSI(6)=[RSI6], RSI(14)=[RSI14] ➔ [超买/超卖/强弱区间]
- **布林通道**: 上轨=[UB], 中轨=[Mid], 下轨=[LB], 带宽=[BW]% ➔ [通道位置]
- **真实波幅**: ATR(14)=[ATR] (日均振幅约 [ATR%]%)

## 四、 关键支撑阻力与风控点位
| 维度 | 关键价位 | 说明 |
| :--- | :--- | :--- |
| **上方阻力位 (Resistance)** | **[R1 / R2 / R3]** | 突破需放量配合 |
| **下方支撑位 (Support)** | **[S1 / S2 / S3]** | 逢低回踩防守位 |
| **建议防守止损点 (2*ATR)** | **[StopLoss]** | 破位需严格止损 |
```
