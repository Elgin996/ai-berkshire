# 投资研究与红队压力测试框架（Antigravity 专版）

对指定目标公司执行团队化投资研究与红队压力测试。主 Agent 扮演 **Team Lead / 调研统筹与审计员**，通过 Antigravity 的 `invoke_subagent` 工具并行启动 4 个专业调研子 Agent，分别从四套经典价值投资检查清单展开深度调研，并经由**确定性金融代码验算、事实底稿 100% 核实、估值敏感性情景推演与独立红队做空证伪（Falsification Pass）**，最终整合输出客观、严谨、多空对抗平衡的机构级投研备忘录。

---

## 核心定位与认知边界

> [!IMPORTANT]
> **本系统是“深度调研底稿秘书与红队质询者（Research Clerk & Red-Team）”，绝非输出自动买卖指令的“投资决策引擎（Decision Engine）”。**

1. **事实、假设与计算三层硬隔离**：
   - **事实层（Fact Layer）**：关键底稿（股本、净负债、历史 3 年 FCF、币种）**100% 强制核实**，严禁使用 15% 随机抽检替代关键财务核验。
   - **假设层（Assumption Layer）**：增长率、终值倍数等属于主观假设，一律以**敏感性情景矩阵**呈现，不给出单一伪精确点位。
   - **计算层（Compute Layer）**：估值算术与硬约束检查强制交由 Python 代码（`financial_rigor.py` / `terminal_value.py`）执行，严禁大模型心算。
2. **多 Agent 的“检查清单”本质（Checklist Lenses）**：
   - 4 个子 Agent 并非 4 个独立心智（共享底层模型先验与搜索层），其实质是 **4 套严密的专业审查清单**。严禁拟人化口号式角色扮演，聚焦事实与逻辑证据链。
3. **剔除虚假精确度（False Precision）**：
   - 废除 1-5 星加权综合评分（如 4.2 / 5.0），废除交易层面的止损点（如 2*ATR）。转为定性检查单通过情况与估值回报率情景推演。
4. **强制引入红队独立证伪审查（Falsification Pass）**：
   - 调研完成后必须进行独立的做空方红队质询，直击看多逻辑的脆弱假设与盲区，防止团队陷入“平庸的多头共识”。

## 执行工作流

### 第一步：AI 研究偏见与信息丰富度自觉评估

在启动研究前，主 Agent 评估目标公司的**信息丰富度等级**，并在研报开头显式标注：

| 丰富度等级 | 公司特征 | AI 研究陷阱 | 应对策略 |
| :---: | :--- | :--- | :--- |
| **A 级（信息充裕）** | 上市多年、市值巨大、券商覆盖极广 | 市场共识极强，AI 输出趋于平庸的多头叙事 | 重点做**反面检验（逆向思考）**与做空逻辑深挖，寻找市场盲区 |
| **B 级（信息适中）** | 上市 1-3 年、覆盖有限、部分数据需推算 | AI 可能以“合理猜测”填补空白 | 每一个推算数据必须强制标注置信度与依据 |
| **C 级（信息稀缺）** | 新上市/冷门股/新兴市场 | 资料不足导致 AI 过度保守或臆测 | 启动**第一性原理模式**，聚焦商业底层要素，不硬凑格式 |

> ⚠️ **核心纪律**：资料多 $\neq$ 投资确定性高；资料少 $\neq$ 投资确定性低。投资确定性来自商业本质与真实自由现金流，不来自资料数量。

---

### 第二步：决策级事实底稿 100% 强核对门禁（Fact Layer）

在启动子 Agent 并行调研前，主 Agent 必须先从官方财报（10-K/年报）或权威独立终端锁定以下**核心决策指标**，严禁模型使用猜测值：

```markdown
### 决策级事实底稿核对表（100% 强校验）
- [ ] 1. 真实当前股价与最新稀释后总股本（Shares Outstanding）
- [ ] 2. 计算真实总市值（Price × Shares）与报告市值对照（误差 <= 1%）
- [ ] 3. 真实净现金 / 净负债 =（货币资金 + 交易性金融资产）- 有息负债总额
- [ ] 4. 过去 3-5 年营业收入、扣非归母净利润、经营性净现金流与资本开支（Capex）
- [ ] 5. 真实自由现金流（FCF = 经营现金流 - 维持性资本开支）
- [ ] 6. 币种统一性核验（区分 CNY、USD、HKD，严禁跨币种混算）
```

    },
    {
      "TypeName": "research",

#### 各子 Agent 详细任务与 Prompt 指南：

1. **商业模式分析师 (Business Model Analyst · 段永平清单)**：
   * **生意本质**：用一句话定义这门生意的本质，拆解收入与利润驱动要素。
   * **客户付费动机与转换成本**：客户为什么买单？不买会有什么后果？生态粘性与迁移壁垒。
   * **五维护城河检验**：品牌/定价权、转换成本、网络效应、规模效应、技术壁垒（逐一给出事实证据，非概念套用）。
   * **TAM 与市值倒挂核验**：测算终端总 TAM，对比当前市值倍数（市值/TAM），从第一性原理核验是否存在“透支全行业天花板”的估值倒挂。
   * **核心追问**：这门生意的核心差异化是什么？十年后其定价权是更强还是更弱？

2. **财务与估值分析师 (Financial & Valuation Analyst · 巴菲特清单)**：
   * **双源验证**：严格遵守 `skills/financial-data.md`，每个核心财务数据取自两个独立数据源，误差 $>1\%$ 显式标注。
   * **三表质量审计**：近 3-5 年营收/净利复合增速、真实 ROE/ROIC、毛利率与经营利润率趋势、现金回款周期。
   * **资产负债与隐形负债排查**：存货与应收账款堰塞排查、研发费用资本化比例、外部对赌/回购条款排查。
   * **程序化工具验算（强制调用）**：
     * 市值验算：`python3 tools/financial_rigor.py verify-market-cap --price {价格} --shares {股本} --reported {市值} --currency {币种}`
     * 估值指标验算：`python3 tools/financial_rigor.py verify-valuation --price {价格} --eps {EPS} --bvps {每股净资产}`
     * 估值情景推演：`python3 tools/financial_rigor.py three-scenario --price {价格} --eps {EPS} --shares {总股本} --growth {乐观} {中性} {悲观} --pe {乐观PE} {中性PE} {悲观PE}`
     * 十年期硬约束审计：`python3 tools/terminal_value.py audit`（校验 C1 同币种、C2 增长约束、C3 离散风险）。
   * **核心追问**：如果股市关闭 5 年，单靠企业产生的自由现金流分红/回购，能否带来满意的回报？

3. **行业与竞争分析师 (Industry & Competition Researcher · 芒格清单)**：
   * **行业全景与 TAM**：行业总空间、未来 5 年增速预期、渗透率拐点。
   * **竞争格局与博弈**：主要竞争对手市场份额、核心优势与短板、新进入者威胁。
   * **产业链议价权**：上游供应商集中度与下游客户议价权。
   * **逆向思考（Inversion）**：列出“这家公司在竞争中被击败的所有潜在路径”。
   * **核心追问**：聪明人为什么会做空这家公司？最可能让多头遭受永久性资本损失的竞争威胁是什么？

4. **风险与受托治理评估师 (Risk & Governance Assessor · 李录清单)**：
   * **管理层受托责任与资本配置**：创始人/CEO 历史重大决策复盘、资本配置记录（回购是否在低估时进行、是否有毁灭价值的盲目并购、分红可持续性）。
   * **利益一致性**：管理层与股东利益是否高度绑定（薪酬结构、持股比例、减持与质押记录）。
   * **宏观与离散风险归属**：地缘政治、反垄断与行业监管、技术范式转移（AI 等颠覆性技术冲击）。
   * **核心追问**：站在 20 年后回看，这家公司是时代不可或缺的基础设施，还是阶段性的过渡品？

### 第四步：红队独立做空证伪审查（Falsification Pass）

当 4 份调研子报告汇总后，主 Agent 启动**红队证伪质询（扮演做空基金经理视角）**，专门对报告中的乐观论点进行压力测试：

1. **攻击乐观假设**：挑出财务与商业模式分析中隐含的 3 个最脆弱假设（如：“维持 20% 高毛利”、“竞品无法突破壁垒”），说明其破裂可能。
2. **推演失败路径**：指出最可能导致公司股价下跌 50% 以上的 2 种黑天鹅或结构性拐点。
3. **识别共识盲区**：指出当前主流卖方研报普遍忽略但至关重要的 1-2 个负面细节。

## 严守执行纪律

1. **零心算原则**：市值、估值指标与情景推演必须通过 `tools/financial_rigor.py` 和 `tools/terminal_value.py` 代码运行产出。
2. **底稿 100% 校验**：总股本、净负债、过去 3 年 FCF、币种属于不可妥协的必核项。
3. **去伪存真**：严禁输出虚假精确的星级评分与技术交易止损点，以敏感性情景矩阵呈现不确定性。
4. **红队必争**：必须包含红队做空证伪审查，严肃列出空方论点与脆弱假设。
