# 投研团队（Antigravity 专版）：四大师并行深度分析框架

对指定目标公司执行团队化投资研究分析。主 Agent 扮演 **Team Lead**，通过 Antigravity 的 `invoke_subagent` 工具并行启动 4 个专业子 Agent，分别从四位投资大师的视角深度调研，并整合输出机构级投研备忘录。

---

## 团队架构与分工

| 角色 (Role) | 负责维度 | 投资大师分析框架 | 核心产出 |
| :--- | :--- | :--- | :--- |
| **team-lead**（主 Agent） | 统筹调度、进度监控、报告汇总、审核准出 | 四大师综合决策 | 最终投资备忘录、星级打分、分层买入点 |
| **Business Model Analyst** | 商业模式本质、产品飞轮与护城河 | **段永平视角**（对的生意） | 生意本质定义、收入结构、定价权、护城河评估 |
| **Financial & Valuation Analyst** | 财务报表、现金流、安全边际与估值验算 | **巴菲特视角**（内在价值） | 三表质量、FCF、程序化市值验算、三情景与十年折现估值 |
| **Industry & Competition Researcher** | 行业格局、竞争威胁与产业链分配 | **芒格视角**（反思与博弈） | 市场规模 TAM、市占率矩阵、核心竞品威胁、产业链地位 |
| **Risk & Management Assessor** | 管理层质量、治理结构、离散风险与颠覆性 | **李录视角**（文明趋势与治理） | CEO能力圈与资本配置、监管/离散风险、10年长期确定性 |

## 执行工作流

### 第一步：AI 研究偏见自觉评估

在启动研究前，主 Agent 首先评估目标公司的**信息丰富度等级**，并在研报开头显式标注：

| 丰富度等级 | 公司特征 | AI 研究陷阱 | 应对策略 |
| :---: | :--- | :--- | :--- |
| **A 级（信息充裕）** | 上市多年、券商覆盖多、媒体报道密集 | 市场共识极强，AI 输出趋于平庸 | 重点做**反面检验（芒格逆向思考）**与非共识盲区深挖 |
| **B 级（信息适中）** | 上市 1-3 年、覆盖有限、部分数据需推算 | AI 可能以“合理猜测”填补空白 | 每一个推算数据必须标注置信度与依据 |
| **C 级（信息稀缺）** | 新上市/冷门股/新兴市场 | 资料不足导致 AI 过度保守或误判 | 启动**第一性原理模式**，聚焦商业底层要素，不硬凑格式 |

> ⚠️ **核心纪律**：资料多 $\neq$ 投资确定性高；资料少 $\neq$ 投资确定性低。投资确定性来自商业本质本身，不来自资料数量。

---

### 第二步：并行启动 4 个 Antigravity 专业子 Agent

主 Agent 调用 `invoke_subagent` 工具，在**单次调用中同时分派 4 个子任务**（`Subagents` 数组中包含 4 个条目）：

```json
{
  "Subagents": [
    {
      "TypeName": "research",
      "Role": "Business Model Analyst",
      "Prompt": "你是投研团队中的商业模式与护城河分析专家（段永平视角）..."
    },
    {
      "TypeName": "research",
      "Role": "Financial & Valuation Analyst",
      "Prompt": "你是投研团队中的财务审计与估值分析专家（巴菲特视角）..."
    },
    {
      "TypeName": "research",
      "Role": "Industry & Competition Researcher",
      "Prompt": "你是投研团队中的行业与竞争格局分析专家（芒格视角）..."
    },
    {
      "TypeName": "research",
      "Role": "Risk & Management Assessor",
      "Prompt": "你是投研团队中的风险与管理层评估专家（李录视角）..."
    }
  ]
}
```

### 第三步：各子 Agent 详细任务规范与 Prompt 模板

#### 1. 商业模式分析师 (Business Model Analyst · 段永平视角)
- **分析内容**：
  1. **生意本质**：用一句话定义这门生意的本质，拆解收入与利润驱动要素。
  2. **产品与飞轮效应**：用户/客户为什么付钱？生态粘性与客户迁移转换成本。
  3. **护城河五维逐一检验**：品牌/定价权、转换成本、网络效应、规模效应、技术壁垒。
  4. **TAM 与第一性原理市值核验**：测算全球/国内该细分赛道终端总 TAM（总可触达市场规模），并与标的公司当前总市值直接做倍数对比（市值/TAM），从第一性原理评估是否存在“市值透支全行业天花板”的宏观倒挂。
  5. **段永平式追问**：这门生意好在哪？如果只能用一句话描述，是什么？

#### 2. 财务与估值分析师 (Financial & Valuation Analyst · 巴菲特视角)
- **分析内容**：
  1. **数据源双重验证**：严格遵守 `skills/financial-data.md`，每个核心财务数据点取自两个独立数据源，误差 $>1\%$ 显式标注。
  2. **三表审计**：近 3-5 年营收/净利复合增速、ROE/ROIC、毛利率/经营利润率、自由现金流 (FCF)、资产负债表与净现金储备。
  3. **营运资本与隐形负债排查**：重点排查营运资金（存货 + 应收账款占资产与营收比例及现金流堰塞），研发费用资本化率，以及控股子公司是否存在外部战投对赌/回购条款（金融负债利息折现摊销对真实利润的侵蚀）。
  4. **程序化金融验算（强制使用 `tools/financial_rigor.py`）**：
     - 市值验算：`python3 tools/financial_rigor.py verify-market-cap --price {价格} --shares {股本} --reported {市值} --currency {币种}`
     - 估值指标验算：`python3 tools/financial_rigor.py verify-valuation --price {价格} --eps {EPS} --bvps {每股净资产}`
     - 三情景估值：`python3 tools/financial_rigor.py three-scenario --price {价格} --eps {EPS} --shares {总股本} --growth {乐观} {中性} {悲观} --pe {乐观PE} {中性PE} {悲观PE}`
  5. **十年折现估值与硬约束（强制使用 `tools/terminal_value.py`）**：
     - 运行 `python3 tools/terminal_value.py audit` 完成 C1 (同币种)、C2 ($r-g \ge 5\%$)、C3 (离散风险归属) 三条硬约束准出检查。
  6. **巴菲特式追问**：如果股市明天关闭 5 年，你愿意以这个价格持有吗？

#### 3. 行业与竞争分析师 (Industry & Competition Researcher · 芒格视角)
- **分析内容**：
  1. **行业全景与 TAM**：行业总市场规模、历史增速与未来天花板预测、渗透率拐点。
  2. **竞争格局矩阵**：主要对手市场份额、核心优势与短板对比、新进入者威胁。
  3. **产业链议价权**：上游供应商与下游大客户集中度分析。
  4. **芒格逆向思考（Inversion）**：列出“这家公司在竞争中可能失败的所有路径”，分析空方核心论点。
  5. **芒格式追问**：我最可能在哪里犯错？聪明人为什么会做空这家公司？

#### 4. 风险与管理层评估师 (Risk & Management Assessor · 李录视角)
- **分析内容**：
  1. **管理层与企业文化**：创始人/CEO 历史重大决策复盘、能力圈、诚信度、资本配置能力（回购/分红/并购）。
  2. **股东利益一致性**：管理层持股比例、激励考核机制、减持与质押情况。
  3. **宏观与离散风险归属**：地缘政治、反垄断/行业监管、技术范式转移（AI颠覆等）。
  4. **李录式追问**：站在 20 年后回看，这家公司是“这个时代的不可或缺者”还是“昙花一现的过渡品”？

### 第五步：保存报告与 15% 随机数据抽检

1. **保存文件**：将完整研报写入 `~/{公司名}投资研究报告_{日期}.md`。
2. **数据抽检准出**：
   ```bash
   # 1. 抽取 15% 关键数据
   python3 tools/report_audit.py extract --report ~/{公司名}投资研究报告_{日期}.md

   # 2. 从独立信源核对填入 JSON

   # 3. 输出判决
   python3 tools/report_audit.py verdict --results '<JSON>' --report ~/{公司名}投资研究报告_{日期}.md
   ```
   - **【准出】**：误差 $\le 1\%$，报告正式发布。
   - **【打回】**：发现数据偏差，修正后重新审计。

## Antigravity 执行纪律

1. **并行分派**：4 个子 Agent 必须通过单次 `invoke_subagent` 调用同时派发，确保研究深度与执行效率。
2. **拒绝心算**：市值、估值指标、三情景估值与终值 IRR 必须通过 `tools/financial_rigor.py` 和 `tools/terminal_value.py` 运行输出。
3. **双源对照**：财务数据必须采纳双独立数据源（参见 `skills/financial-data.md`）。
4. **客观中立**：必须包含 5-7 条看空逻辑，严禁单向吹捧。
